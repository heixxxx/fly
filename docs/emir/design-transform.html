②origin 修正对比：为什么 instance 必须存「经过旋转的 ORIGIN 点」

同一宏（ORIGIN (1, 0)）、同一 orient W、同一放置点 (10, 8)。左图跳过「减 ORIGIN」步骤（错误做法），右图为正确结果。DEF COMPONENTS 给出的 (px, py) 语义是「宏 ORIGIN 的落点」，不是宏左下角 (0, 0) 的落点。

✗ 错误：忽略 ORIGIN 修正（直接 R(W)·m + (10,8)）

✓ 正确：先减 ORIGIN 再变换（R(W)·(m−(1,0)) + (10,8)）

错误式展开（把宏左下角 (0,0) 当锚点）
R(W)·m + (10,8) = [R(W)·(m−ORIGIN) + (10,8)] + R(W)·ORIGIN = 正确结果 + (0, +1)
ORIGIN 点自身的全局位置（与 orient 无关的恒等式）
R(O)·(ORIGIN − ORIGIN) + (px,py) = (0,0) + (px,py) = (px,py) ≡ 放置点
  • DEF 的 (px, py) 是宏 ORIGIN 的落点：正确结果中 ORIGIN 点与放置点 (10, 8) 精确重合，与 orient 取值无关（上式右）。
  • 忽略 ORIGIN 修正时，整个宏多偏移 R(W)·ORIGIN = (0, +1)：放置点处悬空，ORIGIN 落点被错误推到 (10, 9)（上式左）。
  • 因此 instance（std cell 与 block cell）坐标统一存储「经过旋转的 ORIGIN 点」= (px, py) 本身，配 orient 字段即构成完整 DSTransform：不依赖宏内部 ORIGIN 数值即可精确对齐；内部结构（pin 图形 / 子 instance）坐标一律先减 ORIGIN 再入 transform，与链式叠加规则自洽。

示例 1 · std cell 以 orient W 放置：pin 全局坐标逐步计算

// std cell INV（SIZE 0.8×0.4 µm → 1600×800 DBU，ORIGIN (0.1,0) → (200,0)）
// pin Z 图形相对宏左下角 (0.6,0.1)-(0.7,0.3) → (1200,200)-(1400,600) DBU
// DEF：- inst1 INV + ( 100 200 ) W  →  (100×1000, 200×1000) = (100000, 200000) DBU
DSTransform t({100000, 200000}, DSOrientation::W);   // instance 存储坐标 = ORIGIN 落点
// pin Z 全局 = t.apply(pin − ORIGIN)：R(W)=(x,y)→(-y,x)

全局（W 放置于 (100000, 200000)）

示例 2 · block 链式 compose：A（正放）→ B（FN）→ C（W）

DSTransform tA = {{0, 0}, DSOrientation::N};               // A 正放于 top 原点（ORIGIN_A = (0,0)，无修正项）
DSTransform tB = tA.compose({4000, 2000}, DSOrientation::FN);   // B 在 A 内 (4000,2000) FN 放置
DSTransform tC = tB.compose({4000, 800},  DSOrientation::W);    // C 在 B 内 (4000,800) W 放置
// C 内 pin 全局 = tC.apply(pin − ORIGIN_C)，orient 与 anchor 由 compose 一次算出
tA{ anchor (0, 0), orient N }
tB = tA.compose({4000,2000}, FN){ anchor (4000, 2000), orient FN }
tC = tB.compose({4000,800}, W){ anchor (8000, 4200), orient FW（草案）}
全局视图（A 10000×6000 · B 宏 5000×3000 ORIGIN_B (0,3000) · C 宏 600×800）
悬停 / 点击计算行，左侧图形联动高亮：
1tA：A 正放 top 原点anchor_A = (0, 0)，orient_A = N
2tB：anchor_B = R(N)·((4000,2000) − ORIGIN_A) + anchor_A = (4000,2000)；orient_B = compose(N, FN)tB = { (4000, 2000), FN }
3tC：ORIGIN_B = (0,3000) 非零先修正 → R(FN)·((4000,800)−(0,3000)) + anchor_B = (4000,2200) + (4000,2000)；orient_C = compose(FN, W)tC = { (8000, 4200), FW }（FW 为草案）
