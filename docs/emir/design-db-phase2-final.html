核心结构：CMTransform · cell 统一模型 · DSCell pin 三字段

对应裁定：㉔ / ㉜ / P5（GEOTransform） · P7 / P8（cell 统一模型） · P1 / P2 / P3（pin 三字段）

前缀规范：前缀 = 所属模块的标识、一律全大写——common = CM、design = DS、lib = LIB、geometry = GEO（规范：DEVELOPMENT_GUIDELINES.md Section 2.2）。

①GEOTransform（geometry 模块）

template <typename T> // T ∈ int32 / int64 / double class GEOTransform { // 模板类型：适配不同 geometry 坐标类型 GEOPoint<T> offset; // 平移分量 GEOOrientation orient; // 旋转 / 翻转姿态 }
apply(m) = R(orient) · m + offset
  • compose 链式复合——嵌套逐级复合，零修正项；
  • transform_box / transform_polygon——包围盒与多边形整体变换；
  • apply_polygon——多边形逐顶点变换；
  • FLY_SERIALIZE——随序列化宏族持久化。

业务侧仅 t→pos 一行换算（P8 官方语义：placement 对齐放置边界）：

pos = t − transform_box(orient, box).ll()
