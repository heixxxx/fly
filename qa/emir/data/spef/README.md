# spef db 测试数据（规范样张——`gen_spef.py` 确定性生成）

spef db（EMIR ⑤ 寄生数据库，方案
[docs/emir/spef-db-plan.md](../../../../docs/emir/spef-db-plan.md) §9）的
端到端输入件。样张按 IEEE 1481（标准寄生交换格式）的规范形态设计，
由 `gen_spef.py` **确定性生成**（同波形模块 `../waveform/gen_design.py`
的做法：同输入逐字节一致）；每份样张里的数值都能手工推导，推导表在
本文。

## 对齐的设计与建库办法

- **单文件样张**对齐 `../waveform/design/wf_small.def`：14 个实例、16 个
  网（`count[0]`–`count[3]` 四位计数器输出、`n_cnt0_d`–`n_cnt3_d`、
  `n_b1`、`n_b2`、`clk`、`rn`、`clk_div2`、`n_div_d`、`n_and`、
  `n_xor`）。单元引脚名取自 Nangate45 单元库
  （`../timing/NangateOpenCellLibrary.macro.lef`）。
- **块层级样张**对齐 `wf_sub`、`wf_blk_a`、`wf_blk_b`、`wf_blk_top` 四
  件（子定义在前）。设计库里的网名是展平后的层次路径
  （`u_blk_a/n_a1`、`u_blk_a/u_sub/n1`）。三个块级设计声明了对外端
  口，层次化的连接在设计库里成立；经层次端口逻辑相连的各段网是同一
  张**电气网**（见「推导表 4」）。
- 寄生条目按**连接位实例**归属分区，所以设计库必须用**带布线副本**
  （未布线的网不在分区网表里）——派生办法同波形用例
  `qa/emir/test_emir_waveform_flow.py` 的 `_routed_def`（每网补一段
  metal1 几何）。
- 带电源网的派生设计（`sp_pg.spef` 用）= `wf_small.def` 在 `NETS` 段
  之前插入两条通配连接的电源网：

  ```
  SPECIALNETS 2 ;
      - VDD ( * VDD ) + USE POWER
        + ROUTED metal1 340 + SHAPE FOLLOWPIN ( 0 5600 ) ( 40000 5600 ) ;
      - VSS ( * VSS ) + USE GROUND
        + ROUTED metal1 340 + SHAPE FOLLOWPIN ( 0 2800 ) ( 40000 2800 ) ;
  END SPECIALNETS
  ```

  （真实布线工具写出的形态——电源网只有通配连接、没有电源端口。）

## 单位

- `sp_small.spef`、`sp_small_rnet.spef`、`sp_pg.spef`、块层级样张：
  `*C_UNIT 1 FF`——数值即飞法，期望值精确。
- `sp_small_dialect.spef`：`*C_UNIT 1.0 PF`——皮法，带小数的刻度；期望
  值按相对误差 1e-9 比较。

## 多分区设计上的期望

`wf_small` 带布线副本加 `partition_count=16`，设计库实际给出 2 个分区
（分区数是下限）：(0,0) 与 (2,0)。派生副本给每个网加的是同一段几何，
全落在 (0,0)。实例归属：(0,0) 有 9 个（`u_inv_c0`、`u_xor_c1`、
`u_and_c2`、`u_xor_c2`、`u_and_c3a`、`u_xor_c3`、`u_cnt0`、`u_cnt1`、
`u_cnt2`）；(2,0) 有 5 个（`u_cnt3`、`u_inv_div`、`u_div`、`u_and1`、
`u_xor1`）。

用 `sp_small.spef` 建库：条目落点 = 本区有连接位的网（原始条目）+
本区网表里所在电气网有负载的网（补全条目）。这个设计是平展的，派生
副本的几何全在 (0,0)：

- (0,0)：连接位在本区的 12 个网（`count[0]`、`n_cnt0_d`、`count[1]`、
  `n_cnt1_d`、`n_b1`、`count[2]`、`n_cnt2_d`、`n_b2`、`count[3]`、
  `n_cnt3_d`、`clk`、`rn`）+ 网表补全的 3 个网（`clk_div2`、`n_div_d`、
  `n_and`：连接位只在 (2,0)，几何在 (0,0) 的网表里）。`n_xor` 没有被
  描述，不补。
- (2,0)：连接位在本区的 10 个网（`count[0]`–`count[3]`、`n_cnt3_d`、
  `clk`、`rn`、`clk_div2`、`n_div_d`、`n_and`）；本区网表为空，没有
  补全条目。

分区对象：`PART_0_0.NET_LOAD` 15 条、`PART_2_0.NET_LOAD` 10 条；同一
张网在两个分区里数值相同。`get_net_load(网)["partitions"]`：只在
(0,0) 的 5 个网（`n_cnt0_d`、`n_cnt1_d`、`n_b1`、`n_cnt2_d`、`n_b2`）；
两个分区都有的 10 个网；`n_xor` 为 `None`。

覆盖率的分母是**本区实例连接里出现的已布线信号网**：

| 分区 | 已布线信号网 | 覆盖 | 未覆盖 | 未覆盖实例 | 零电容实例 |
|---|---|---|---|---|---|
| (0,0) | 12 | 12 | 0 | 0 | 0 |
| (2,0) | 11 | 10 | 1（n_xor） | 1（u_xor1） | 1（u_inv_div） |
| 合计 | 23 | 22 | 1 | 1 | 1 |

(0,0) 的 12 个网 = 它的 9 个实例所连的全部网 = `count[0]`、
`n_cnt0_d`、`count[1]`、`n_cnt1_d`、`n_b1`、`count[2]`、`n_cnt2_d`、
`n_b2`、`count[3]`、`n_cnt3_d`、`clk`、`rn`。(2,0) 的 11 个网 =
`count[0]`、`count[1]`、`count[2]`、`count[3]`、`n_cnt3_d`、`clk`、
`rn`、`clk_div2`、`n_div_d`、`n_and`、`n_xor`。

行首值与明细合计不一致：2——逐分区的条目合计（同一张网出现在几个
分区就计几次，与覆盖率同口径）：`n_and` 在两个分区都有条目，各计
一次。最大相对偏差 1/46。

**合并口径**（两层）：

1. 单个网编号内：同作用域保留首份（裁定 8），跨作用域相加。
2. 同一张电气网的各段相加——行首、对地、耦合分别相加，来源位图按位
   或，缩减形态标记相与。不同网编号之间不存在「重合」。

**条目落点**：本区有原始条目的网 + 本区网表里所在电气网有负载的网
（补全条目，数值是电气网合计）。读库 `get_net_load` 按任意一段的网
编号查，拿到的都是整张电气网的负载；字典多一个键 `electrical_members`
（全部成员网编号，升序）。汇总多一个字段 `electrical_net_count`（含两
个及以上成员的电气网数）= 5。覆盖率：一张网已覆盖 = 它所在的电气网
有负载。

按输入顺序 `[blk_top, blk_a_inst(block_inst=u_blk_a),
blk_top_overlap, blk_strip(block_inst=u_blk_a, strip_prefix=tb/u_dut),
blk_sub_cell(block_cell=wf_sub)]` 建库。作用域：两个纯路径文件共用一
个；两个绑 `u_blk_a` 的文件共用一个；块定义绑定的文件一个。

## 大规模用例（不在本目录）

`qa/emir/test_emir_spef_big.py` 在用例内按 `wf_big.def` 的 20002 个网程
序化生成寄生文件（约 38 MB，写到 `qa_tmp` 下）：每个网一段，行首 =
(序号 mod 1000) + 7、耦合 = 序号 mod 7、对地 = 行首 − 耦合（行首不小于
7、耦合最大是 6，对地恒为正——负的电容记录是破损网）；序号是网在 DEF
`NETS` 段的书写顺序。每段之后一条约 1.8 KB 的填充注释，把文件撑过两
个最小切块（16 MB）。切块大小的最小值是 16 MB，于是被切成 3 块；缺省
256 MB 是 1 块。两个库的建库结果除切块数外逐条相同。
